# Support

[简体中文](SUPPORT.zh-CN.md)

Support is best effort. Agent Docs promises no response, acknowledgement, diagnosis, fix, merge, or release time.

- Ask usage and configuration questions in [Discussions](https://github.com/Cusnd/agent-docs/discussions).
- Report reproducible defects, feature requests, and documentation problems with the matching [Issue form](https://github.com/Cusnd/agent-docs/issues/new/choose).
- Report vulnerabilities only through [Private Vulnerability Reporting](https://github.com/Cusnd/agent-docs/security/advisories/new).

Include the Agent Docs version, Codex CLI version, Node.js version, operating system, repository shape such as clone or linked worktree, the smallest reproduction, and sanitized output from `agent-docs status --json` and `agent-docs validate --json`. Never post credentials, private paths, complete terminal captures, or private repository content.

Only the compatibility combinations explicitly marked as CI-verified or observed in the [README](README.md) have evidence. Other combinations are unverified; reports are welcome without implying support.
