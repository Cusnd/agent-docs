# Governance

[简体中文](GOVERNANCE.zh-CN.md)

Agent Docs currently has one maintainer: [@Cusnd](https://github.com/Cusnd). The maintainer controls sensitive repository settings and has final authority over triage, moderation, merges, releases, security advisories, supported versions, and project direction.

External Issues, Discussions, and pull requests are welcome. Participation does not grant a project role, merge authority, or a promise of acceptance. New collaborators are added manually with the lowest practical permission and only when ongoing responsibilities require it. Roles and access are reviewed when project membership changes.

Substantial changes should begin with an Issue or Discussion and include compatibility, security, documentation, and test consequences. Routine fixes can proceed directly by pull request. After the bootstrap commit, `main` changes require a pull request and required checks. The single-maintainer configuration requires zero approvals to avoid self-review deadlock, while conversation resolution, current branch state, linear history, and status checks remain enforced.

The public governance and Code of Conduct contact is [me@esoren.com](mailto:me@esoren.com). Vulnerabilities must use the separate private reporting channel in [SECURITY.md](SECURITY.md).

Governance and maintenance are best effort and carry no response or decision SLA.
