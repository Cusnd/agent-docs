# OpenSSF OSPS Baseline Level 1 self-assessment

[简体中文](osps-baseline.zh-CN.md)

- **Baseline:** [OSPS Baseline v2026.02.19](https://baseline.openssf.org/versions/2026-02-19)
- **Scope:** `Cusnd/agent-docs`, its source repository, and the v0.2.0 Marketplace release process
- **Assessment type:** project self-assessment; not an OpenSSF or third-party certification
- **Evidence date:** 2026-08-18
- **Current phase:** v0.2.0 published; source, repository controls, and downloaded release assets verified

Level 1 applies to code and non-code projects. Every Level 1 control in the named baseline is mapped below. `Met` records project evidence, not independent certification. The separate [release report](release-verification.md) records the published-asset acceptance evidence.

## Remote evidence snapshot

- The [public repository](https://github.com/Cusnd/agent-docs) uses `main`, enables Issues and Discussions, disables Wiki and Projects, permits squash merges only, and deletes merged branches. Authenticated API readback found only `@Cusnd` with access.
- The active [`main` ruleset](https://github.com/Cusnd/agent-docs/rules/21000773) has no bypass actor. It requires pull requests, current-head checks, resolved conversations, linear history, and `CI / gate`, `Security / codeql`, and `Security / dependency-review`; it blocks deletion and force-push.
- Active tag rulesets restrict [`v*` creation to `@Cusnd`](https://github.com/Cusnd/agent-docs/rules/21000782) and make [`v*` tags immutable](https://github.com/Cusnd/agent-docs/rules/21000787) with no update/deletion bypass.
- Default Actions token permissions are read-only and Actions cannot approve pull requests. Private Vulnerability Reporting, Dependabot alerts/security updates, secret scanning, and push protection are enabled.
- The final pre-release [CI run](https://github.com/Cusnd/agent-docs/actions/runs/32162080649) passed Windows, Linux, and macOS on Node.js 22, 24, and 26, three deterministic package jobs, isolated installs, the cross-OS digest comparison, and `CI / gate`. The matching [Security run](https://github.com/Cusnd/agent-docs/actions/runs/32162080586) passed CodeQL, dependency review, and runtime/public-content checks.
- GitHub's Community Profile API reported 100%. The final pre-tag [Scorecard run](https://github.com/Cusnd/agent-docs/actions/runs/32164767456) published a real score of 6.8 for commit `569fb8a1544d0dfcb95552c953048df5be0e6b5f` with Scorecard v5.5.0; no score threshold is claimed.
- The annotated, protected [`v0.2.0` release](https://github.com/Cusnd/agent-docs/releases/tag/v0.2.0) targets commit `569fb8a1544d0dfcb95552c953048df5be0e6b5f`. [Release run 32165631144](https://github.com/Cusnd/agent-docs/actions/runs/32165631144) passed all nine OS/Node tests, all three deterministic package jobs, and attested publication.
- The downloaded 67,231-byte Marketplace ZIP matched `SHA256SUMS` and all three package jobs at SHA-256 `70723ad7eb654af02d36c73ca3ea35bda6a5a8043513cf66c5e847e42e65863a`; both published assets passed constrained GitHub artifact-attestation verification and the ZIP passed the isolated installation smoke. See the [release report](release-verification.md).

## Release decision

No Level 1 implementation control remains `Pending`. The protected badge pull request passed before tag creation, and the [release report](release-verification.md) records the immutable tag, remote ZIP and checksum, both attestations, successful post-release link run, and isolated installation of the downloaded asset. The v0.2.0 project self-assessment is complete; this remains a self-assessment rather than OpenSSF or third-party certification.
