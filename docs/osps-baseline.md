# OpenSSF OSPS Baseline Level 1 self-assessment

[简体中文](osps-baseline.zh-CN.md)

- **Baseline:** [OSPS Baseline v2026.02.19](https://baseline.openssf.org/versions/2026-02-19)
- **Scope:** `Cusnd/agent-docs`, source repository and v0.2.0 Marketplace release
- **Assessment type:** project self-assessment; not an OpenSSF or third-party certification
- **Current phase:** local implementation complete only after the quality gate; remote evidence remains pending until GitHub readback

The baseline identifies Level 1 as applicable to any code or non-code project. This mapping covers every Level 1 control in the specified version. `Pending` is release-blocking; it must become `Met` with a public or reproducible evidence link before the `v0.2.0` tag is created.

## Release decision

The assessment is incomplete while any row is `Pending`. After remote configuration, the badge pull request must replace each pending rationale with a public URL or sanitized GitHub API readback. The release report records the exact repository commit, workflow runs, ruleset identifiers, Community Profile result, Scorecard run, assets, checksums, and attestations.
