# D-20260818-1259-4YJO: Publish sanitized Agent Docs records as repository dogfooding

- **Date:** 2026-08-18T12:59:18.747Z
- **Status:** Accepted
- **Requirements:** R-20260818-124939-69OB
- **Supersedes:** None

## Context

Publicly committing repository operational records improves auditability and proves the handoff model, but Git history makes accidental disclosure difficult to reverse.

## Decision

Keep this repository docs/agent under version control, enforce a repository-specific public-content gate, and exclude docs/agent from the distributable Marketplace ZIP.

## Trade-offs

Public dogfooding gives contributors concrete evidence and tests the product on itself, while adding permanent review and redaction obligations.

## Consequences

Committed records must use repository-relative evidence and must not contain machine paths, task or thread identifiers, private URLs, transcripts, full command output, or secrets; the generic plugin validator remains suitable for private repositories.
